1. ТРЕБОВАНИЯ
-----------------------------------------------------------
- Windows 10/11 (инструкция для CMD)
- Python 3.9 или выше (добавлен в PATH)
- Google Chrome (последняя версия) – для скрапера (опционально)
- Telegram аккаунт и токен бота (получить у @BotFather)
- Доступ в интернет

-----------------------------------------------------------
2. УСТАНОВКА И НАСТРОЙКА ОКРУЖЕНИЯ
-----------------------------------------------------------
2.1. Откройте командную строку (CMD) и перейдите в папку проекта:
     cd C:\путь\к\api_telegram_bot

2.2. Создайте виртуальное окружение:
     python -m venv venv

2.3. Активируйте его:
     venv\Scripts\activate

2.4. Установите зависимости (если есть requirements.txt):
     pip install -r requirements.txt

     Если файла нет, установите вручную:
     pip install selenium webdriver-manager selenium-stealth beautifulsoup4 prefect pandas fastapi uvicorn pydantic python-telegram-bot python-dotenv requests

2.5. Создайте в корне проекта файл .env со следующим содержимым (замените ВАШ_ТОКЕН):
     TELEGRAM_BOT_TOKEN=ВАШ_ТОКЕН

-----------------------------------------------------------
3. ПОДГОТОВКА БАЗЫ ДАННЫХ
-----------------------------------------------------------
База данных должна лежать в data/raw/spb_rentals.db.

Вариант А (тестовые данные, если есть файл listings.sql):
     sqlite3 data/raw/spb_rentals.db < listings.sql

Вариант Б (собрать реальные объявления с BN.ru):
     python -m scraper.bn_scraper
     (скрапер откроет браузер и соберёт первые 3 страницы)

-----------------------------------------------------------
4. ЗАПУСК API (FASTAPI)
-----------------------------------------------------------
ОТКРОЙТЕ НОВОЕ ОКНО CMD. В нём выполните:
     cd C:\путь\к\api_telegram_bot
     venv\Scripts\activate
     uvicorn api.app:app --reload

Успешный запуск:
     INFO: Uvicorn running on http://127.0.0.1:8000
     INFO: Application startup complete.

API работает. Не закрывайте это окно!

ИНСТРУКЦИЯ: КАК УСТАНОВИТЬ ТОКЕН БОТА В ФАЙЛ .env
===================================================

. ПОЛУЧИТЕ ТОКЕН У BOTFATHER В TELEGRAM
----------------------------------------
- Откройте Telegram и найдите бота @BotFather.
- Отправьте команду /newbot.
- Придумайте имя и username для бота (username должен оканчиваться на "bot").
- После создания BotFather выдаст токен – строку вида:
    1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
- Скопируйте этот токен (он понадобится в шаге 3).

. СОЗДАЙТЕ ФАЙЛ .env В КОРНЕВОЙ ПАПКЕ ПРОЕКТА
-----------------------------------------------
Корневая папка проекта – это папка, в которой лежат подпапки api, scraper, bot.

Способ А (через проводник Windows):
- Откройте папку проекта.
- Нажмите правой кнопкой мыши → Создать → Текстовый документ.
- Назовите его .env (включая точку в начале).
- Если Windows не разрешает название с точкой, создайте файл env.txt, затем переименуйте его в .env (расширение .txt должно исчезнуть).

Способ Б (через командную строку CMD):
- Откройте CMD, перейдите в папку проекта:
    cd C:\путь\к\проекту
- Выполните команду:
    echo TELEGRAM_BOT_TOKEN=ваш_токен > .env

. ВПИШИТЕ ТОКЕН В ФАЙЛ .env
----------------------------
Откройте файл .env любым текстовым редактором (Блокнот, Notepad++ и т.д.).
Внутри файла должна быть одна строка:
    TELEGRAM_BOT_TOKEN=скопированный_токен

Например:
    TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

Сохраните файл. Убедитесь, что нет лишних пробелов, кавычек или точек с запятой.

. ПРОВЕРЬТЕ, ЧТО БИБЛИОТЕКА PYTHON-DOTENV УСТАНОВЛЕНА
------------------------------------------------------
Откройте CMD, активируйте виртуальное окружение (venv\Scripts\activate) и выполните:
    pip install python-dotenv

. ЗАПУСТИТЕ БОТА (УБЕДИТЕСЬ, ЧТО ТОКЕН ЧИТАЕТСЯ)
---------------------------------------------------
В корне проекта выполните:
    python -m bot.bot

Если токен верный, бот запустится без ошибок. Если появляется "No module named 'dotenv'" – установите python-dotenv (шаг 4).

ВАЖНО:
- Никогда не публикуйте файл .env в открытых репозиториях (GitHub). Добавьте .env в .gitignore.
- Если бот не запускается с ошибкой "Не задан TELEGRAM_BOT_TOKEN", проверьте:
    * имя файла – должно быть .env, а не .env.txt (включите показ расширений в Windows).
    * содержимое файла – строка должна быть точной (без кавычек, пробелов после =).
    * файл .env должен лежать в той же папке, откуда запускается бот (корень проекта).

Готово! Теперь бот сможет подключиться к Telegram.

6. ПРОВЕРКА РАБОТЫ БОТА (КОМАНДЫ И ПРИМЕРЫ)
-----------------------------------------------------------
6.1. В Telegram найдите своего бота (по имени, которое вы задали у @BotFather) и отправьте /start.
     Бот ответит приветствием и покажет главное меню с кнопками.

6.2. Основные команды:
     /start      – главное меню
     /help       – справка
     /stats      – статистика (средняя цена, кол-во активных объявлений)
     /listings   – поиск с параметрами (примеры ниже)
     /search     – интерактивный поиск с кнопками

6.3. Примеры поиска через /listings:
     - Студии до 30 000 руб:
          /listings rooms=0 max_price=30000 limit=5
     - 1-комнатные, площадь 30-50 м², сортировка по цене (дорогие сверху):
          /listings rooms=1 min_area=30 max_area=50 sort_by=price order=desc
     - Поиск по адресу (часть названия):
          /listings address=Мурино limit=3

6.4. Навигация по результатам:
     После выполнения /listings бот показывает одно объявление и кнопки:
     ▶️ Следующее – листает объявления в пределах текущей страницы.
     Когда объявления заканчиваются, автоматически загружается следующая страница (пагинация).
     🔍 Новый поиск – сбрасывает фильтры и возвращает в главное меню.

7. ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ
-----------------------------------------------------------
Проблема: ModuleNotFoundError: No module named 'api'
Решение: Запускайте uvicorn из корня проекта, а не из папки api.

Проблема: Бот не отвечает или пишет ошибку соединения
Решение: Убедитесь, что API запущен (http://127.0.0.1:8000). Проверьте командой: curl http://127.0.0.1:8000/stats (если есть curl) или откройте в браузере.

Проблема: В БД нет данных или цена NULL
Решение: Запустите скрапер заново (удалите старую БД). Если цена всё равно NULL, проверьте файлы config.py и parser.py – используйте последние исправленные версии.

Проблема: Скрапер не открывает браузер
Решение: В bn_scraper.py убедитесь, что headless=False (по умолчанию так и есть). Или проверьте установку ChromeDriver (webdriver-manager загрузит автоматически).

Проблема: FastAPIDeprecationWarning: regex
Решение: В api/app.py замените параметр regex= на pattern=. Исправленная версия уже в репозитории.
